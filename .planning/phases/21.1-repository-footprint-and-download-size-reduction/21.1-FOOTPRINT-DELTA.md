# Phase 21.1 Footprint Delta

## Source Distribution

The pre-fix baseline carried `5,551,066,900` tracked APDR target bytes across 11 `tools/apdr/target-*` roots. The candidate artifact has `tracked_target_paths: []` and `tracked_target_bytes: 0`, so Phase 21.1 removes that source-distributed build-output bloat from fresh checkouts and GitHub downloads without rewriting history.

## Local Footprint

Measured on `/Users/dannyguan/Documents/fse-aiware-python-dependencies`:

- `local_cache_bytes`: `16,423,664,046` -> `1,381,915,956` (`-15,041,748,090`)
- `local_target_bytes`: `20,451,258,961` -> `0` (`-20,451,258,961`)
- `tool_tree_bytes`: `38,507,986,604` -> `3,014,979,553` (`-35,493,007,051`)

These numbers come from the Phase 21.1 baseline and candidate JSON artifacts after the cleanup helper removed repo-local APDR target trees and pruned the legacy repo-local `.apdr-cache`.

## Cleanup Path

The proof candidate was produced with the supported operator command below, which keeps Cargo build output in `/tmp` during cleanup so the cleanup pass does not recreate repo-local target bloat:

```bash
bash scripts/cleanup-apdr-footprint.sh --apply --cache-path tools/apdr/.apdr-cache --target-dir /tmp/phase21_1-apdr-target
```

The helper also supports `--dry-run` for inspection-first use and documents `--cache-path` plus `--target-dir` overrides so developers can reclaim bytes without knowing APDR's internal directory layout ahead of time.

## Caveats

- This proof improves the current working tree and future defaults; it does not rewrite old commits, so `.git` size stays effectively unchanged in the artifact pair.
- The candidate artifact measures repo-local APDR footprint. It does not claim a full-machine cleanup of every external cache path a developer may have used historically.
- The source-distribution win is permanent for new commits, while the local-footprint win depends on using the new defaults or the cleanup helper when old build/cache directories already exist.
