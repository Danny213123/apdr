Add cache hit/miss detection and logging per D-15:

1. **In complete_json() method** (around line 178+), add timing and cache detection:
   ```python
   def complete_json(
       self,
       system_prompt: str,
       user_prompt: str,
       response_model: type[T],
       max_tokens: int = 512,
       num_ctx: int = 4096,
   ) -> T | None:
       import time
       started = time.time()

       # ... existing completion call ...

       try:
           result = self._instructor_client.chat.completions.create(
               model=self._litellm_model(),
               messages=[
                   {"role": "system", "content": system_prompt},
                   {"role": "user", "content": user_prompt},
               ],
               response_model=response_model,
               max_tokens=max_tokens,
               temperature=0.0,
               num_ctx=num_ctx,
           )

           duration_ms = int((time.time() - started) * 1000)

           # Detect cache hit - LiteLLM may not expose this directly
           # Heuristic: very fast responses (<100ms) are likely cache hits
           # Better approach: check if litellm.cache has hit tracking
           cache_hit = duration_ms < 100  # Heuristic for now

           logger.info(
               "LLM completion finished",
               extra={
                   "event": "llm_completion",
                   "cache_hit": cache_hit,
                   "duration_ms": duration_ms,
                   "model": self.model,
                   "prompt_version": self._prompt_version_hash,
               }
           )

           return result
       except Exception as e:
           logger.error("LLM completion failed: %s", e)
           return None
   ```

NOTE: Cache hit detection is heuristic-based (<100ms = cache hit) because research indicates LiteLLM may not expose cache metadata directly. This is a known limitation documented in Open Questions.

If LiteLLM does expose cache hit metadata, update the detection logic. For now, the heuristic is sufficient for metrics tracking.
