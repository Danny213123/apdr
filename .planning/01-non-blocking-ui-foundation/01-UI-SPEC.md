## Accessibility Contract

Existing patterns (ARIA already present):

- Tab navigation: `role="button"`, `aria-selected`, `aria-label`
- Dropdown menus: `role="listbox"`, `role="option"`, `aria-expanded`, `aria-haspopup`
- Collapsible panels: `<details>` native semantics
- Progress: Visual only (not `role="progressbar"` - terminal aesthetic)

New requirements for Phase 1:

- SSE status: `aria-live="polite"` region for connection state
- Streaming activity: `aria-live="polite"` for new case completions
- Activity log: Limit to 10 items, older items removed (screen reader overflow prevention)

## Performance Contract

Existing baseline:
- UI startup: 3+ seconds (blocking database load)
- Frame rate: Assumed 60fps during idle
- Memory: Not measured

Phase 1 targets (from REQUIREMENTS.md):
- **UI-01:** Interactive within **500ms** of page load
- **UI-04:** Sustain **60fps** during result updates
- **UI-05:** Memory stable in long-running benchmarks (<50MB growth over 30 min)

Implementation constraints:
- Use `requestAnimationFrame` throttling when >5 SSE events/sec
- Batch DOM updates: collect events for 16ms (1 frame), then append all
- Event listener cleanup: Use `AbortController` for SSE EventSource, remove on disconnect
- Virtual scrolling: NOT needed (max ~100 cases visible per phase requirements)

## Implementation Notes for Planner/Executor

**What NOT to change:**
- Existing color tokens (terminal theme is established brand)
- Font size (14px is locked for terminal aesthetic)
- Component structure (HTML is semantic and accessible)
- CSS Grid/Flexbox layouts (responsive and functional)

**What TO add:**
- SSE EventSource client (`main.js` function: `setupSSE()`)
- SSE reconnection logic with exponential backoff
- Real-time DOM append functions (throttled via `requestAnimationFrame`)
- Connection state indicator component
- Activity stream component with auto-pruning (max 10 items)

**Files to modify:**
- `web/src/main.js` — Add SSE client, streaming update functions
- `web/src/styles.css` — Add `.sse-status-indicator`, `.streaming-badge`, fade-in animations
- `web/index.html` — Add SSE status region, activity stream container
- Backend (out of scope for UI-SPEC, but required): Flask SSE endpoint at `/api/stream/benchmark/{runId}`

**Dependencies:**
- Flask backend must implement `/api/stream/benchmark/{runId}` returning `text/event-stream`
- Event format: `data: {json}\n\n` with fields: `type`, `caseId`, `status`, `progress`, `timestamp`
- Heartbeat events every 15s to prevent proxy buffering
